# Project Setup

Follow the steps below to get the project running.

## 1. Clone the Repository

```bash
git clone <repository-url>
cd <project-folder>
```

## 2. Add Your API Keys

Before running the project, add your own API keys to the appropriate configuration file (such as `.env`).

## 3. Create a Virtual Environment

```bash
uv venv
```

## 4. Activate the Virtual Environment

### Windows

```bash
.venv\Scripts\activate
```

### macOS/Linux

```bash
source .venv/bin/activate
```

## 5. Install Dependencies

```bash
uv pip install -r requirements.txt
```

## 6. Run the Project

Run the application using the appropriate command for your project.

---

That's it! You're ready to go.
